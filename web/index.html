How it works

01 / LLM

What is an LLM?

A large language model is a program that has read an enormous amount of text and learned one skill: guessing the next word.

Give it the start of a sentence and it scores every possible continuation, picks one, and repeats. Whole answers are built one word at a time this way.

02 / Post-training

What is post-training?

Out of the box, the model knows a lot but sounds like nobody in particular. Post-training is everything done afterwards to shape how it behaves.

Here the big model is left untouched. A small add-on, called an adapter, is trained on one person's answers until the replies start to sound like them. Under 1% of the numbers in the model change.

03 / Dataset

What is a dataset?

A dataset is the set of examples the model learns from. For this project each example is a question and the real answer one person gave to it.

The questions cover work, casual chat, things to politely decline, and "are you real?", so the model learns the writing style and also where to stop.
